# The format, tracker-like:
#   tempo N, swing P            the tempo (BPM) and the swing of the odd 16ths (%)
#   chord NAME notes...         a chord, its notes as names (C4 is MIDI 60)
#   drums NAME ... end          a drum pattern: one row per instrument,
#                               K kick, S snare, G ghost snare, H closed hat,
#                               O open hat, R ride, C crash; 16 steps a bar,
#                               bars joined with |; X accent, x hit, o soft
#   bass NAME ... end           a bass line: one token a 16th, a note name,
#                               - hold, . release; ~ before a note glides into it
#   stab NAME ... end           the chord stabs: one row, x hit, X accent
#   arp NAME ... end            the arpeggio: one token a 16th, 0..9 an index
#                               into the chord's notes over two octaves, . rest
#   harm NAME chords...         a chord a bar
#   section NAME bars N [bass reese|sub|both|none] [pad 0..1] [loop BAR]
#     drums|bass|stab|arp|harm patterns...   (each pattern fills its bars,
#                               - one bar of silence; the list is repeated
#                               to fill the section)
#     fx ROW                    a character a bar: C crash, I impact (a
#                               reversed swell before it), . nothing
#   end
